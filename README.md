# The Fart Button

One button. Zero dignity. Infinite possibilities.

## Use it

- Click the giant orange **FART** button, or press **Space**.
- Every press streams a randomized real fart recording from a curated web sample bank.
- Your successful emission count is saved locally.

An internet connection is required for sound playback. Samples are CC0/public-domain recordings sourced from [FartSoundboard](https://fartsoundboard.com/sounds/), [DSISStudios on Freesound](https://freesound.org/people/DSISStudios/packs/14789/), and [BigSoundBank](https://bigsoundbank.com/flatulence-4-s1031.html).

## Run

```bash
npm install
npm start
```

You can also use `PLAY-IN-BROWSER.cmd` to run it in your default browser, or build a portable Windows app with:

```bash
npm run pack
```
